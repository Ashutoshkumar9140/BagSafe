# BagSafe

BagSafe is a React project that helps students find a safe and affordable place to stay near their exam center.

Students can search for shelters, check the details, send a request to a homeowner, and chat with them. Homeowners can add their shelters and manage booking requests.

## Features

* Student and Homeowner login/signup
* Student profile and verification
* Search shelters by city and exam area
* Shelter details with price, capacity and amenities
* Send booking requests
* Homeowner can accept or reject requests
* Chat between students and homeowners
* Demo wallet and payment system
* Homeowners can add and manage shelters
* Light and dark mode
* Responsive design

## Technologies

React
JavaScript
React Router
Tailwind CSS
Vite
LocalStorage

## Run the Project

Install the dependencies:

npm install

Start the project:

npm run dev

Then open the local URL shown in the terminal.

## Note

This is a demo project. User data, requests, chat and wallet information are stored in the browser using LocalStorage.

The shelters and payment system are only for demonstration and are not connected to real homeowners or real payments.
